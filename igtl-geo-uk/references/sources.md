# Rules register and skill updates

Read this file when you need to cite a specific rule, check an effective date, work through a disputed wording or update the skill itself.

**Priority.** The wording in the reference files is a saved summary of the rules as of the date they were checked. If the current primary source differs, the primary source prevails; tell the task owner about the discrepancy.

**Columns.** "Checked" is the date the rule in the skill was checked against the source. It is the date of the skill check: facts about a specific operator are checked separately for each task.

**Verification statuses:**
- **Primary source**: checked against the text of the rule or the official page of the regulator, legislator, HMRC, ASA/CAP or the organisation itself.
- **Primary source (guidance)**: checked against official guidance, a consultation response or a regulator's blog; it does not create a rule of its own.
- **Secondary source**: confirmed by law firm publications or the trade press; no primary source found.

All addresses use https://.

## How to update the skill

1. Once a quarter, and before each release of the skill to clients, check the Gambling Commission pages: LCCP upcoming changes (www.gamblingcommission.gov.uk/licensees-and-businesses/lccp/upcoming-changes), RTS upcoming changes (www.gamblingcommission.gov.uk/licensees-and-businesses/guide/page/rts-upcoming-changes) and the news section. Check separately any dates that have already been moved (RTS 12) or not yet announced (Financial Risk Assessments).
2. For each rule that has changed, update its register row (source, provision, effective date, status, check date), then the text in the topic reference file and, if the rule appears in "Key rules at a glance" or the checklist, in `SKILL.md`.
3. Where possible, re-check rows with the status "Secondary source" against a primary source and update the status.
4. Update the version and date in the `SKILL.md` header and add an entry to the change log below.
