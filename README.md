### `igaming-ai-humanizer/`

Rewrites or generates iGaming/casino/betting copy — site content, slot
reviews, bonus pages, landing pages — so it drops the lexical, grammatical,
structural, and statistical patterns that make text read as AI-generated.

Covers English and Russian copy, with an iGaming-specific lexicon (the
"seamless experience" / "unbeatable bonus" kind of filler every casino
site is drowning in) on top of general AI-detection patterns.

```
igaming-ai-humanizer/
├── SKILL.md                      # entry point, two modes: edit / write from scratch
└── references/
    ├── en-markers.md             # English AI-text markers
    ├── igaming-lexicon.md        # iGaming-specific clichés, 10 categories
    ├── ru-markers.md             # Russian-language markers
    ├── structure-and-rhythm.md   # rhythm, punctuation, composition rules
    ├── master-prompt.md          # standalone prompt block — usable on its own
    └── self-check-checklist.md   # final pass before output
```
